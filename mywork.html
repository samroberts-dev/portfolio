Web Technologies Portfolio

Overview

A staged portfolio created for my Certificate IV Web Technologies studies. The project brings together semantic HTML, responsive CSS layouts and JavaScript, including forms that request country flags and dad jokes from an API. A Tailwind CSS dashboard links the portfolio phases together.

Technologies used

  • HTML5
  • CSS3
  • JavaScript
  • Tailwind CSS
  • REST APIs
  • Git

What I learned

This project gave me practice structuring pages with semantic HTML, adapting layouts for different screen sizes and keeping styling and JavaScript in separate files. I also worked with API requests, displayed responses on the page and handled errors. Using Git helped me track changes as I built each phase.

Database Customisation

Overview

A Windows desktop application built with C# and WPF to explore a MySQL database. The current code loads database tables, displays their fields and searches records using a selected table, field and value. It is an ongoing project, with further database customisation features still to develop.

Technologies used

  • C#
  • WPF
  • XAML
  • .NET 8
  • MySQL
  • SQL
  • MySql.Data

What I learned

This project gave me practice connecting a desktop application to MySQL and using SQL queries to retrieve information. I worked with database schema information, data readers and WPF controls to display tables and fields. I also practised responding to interface events and handling database errors.

Guessing Game

Overview

A Python command-line number guessing game where players try to find a randomly selected number between 1 and 1,000. The game gives higher or lower hints and validates each guess. It also includes a basic account system and saves player and global statistics in JSON files, including games played, average guesses and best results.

Technologies used

  • Python
  • JSON
  • random
  • hashlib
  • File handling
  • Git

What I learned

This project gave me practice breaking a program into functions and using loops and conditions to control gameplay. I worked with random numbers, validated user input and handled invalid entries with exceptions. Saving and loading JSON files helped me understand how to keep player statistics between runs, and I explored password hashing with hashlib.
