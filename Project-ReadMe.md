# Personal Portfolio Website
This project is a personal portfolio website for me, created as part of the Certificate IV in Information Technology (Programming), for my Web Technologies Assessment.

This website will introduce everyone to me, present my skills, experience and education, and showcase my projects. It will include Home, About, Resume, Projects, Sample Project, and Contact Pages.

The site will be coded in HTML, CSS and JavaScript, with Git being used as a version controller, and GitHub pages being used to "host" the final website.
