# Personal Portfolio Website
This project is a personal portfolio website for me, created as part of the Certificate IV in Information Technology (Programming), for my Web Technologies Assessment.

This website will introduce everyone to me, present my skills, experience and education, and showcase my projects. It will include Home, About, Resume, Projects, Sample Project, and Contact Pages.

The site will be coded in HTML, CSS and JavaScript, with Git being used as a version controller, and GitHub pages being used to "host" the final website.

## Styling with Tailwind CSS

The Home and About pages use Tailwind CSS 3.4.19 utilities directly in the HTML.
The remaining empty pages are still to be built. Featured projects are deferred.

### Build the stylesheet

From this Project folder, run `npm install` once, then `npm run build`.
Use `npm run watch` while editing to rebuild automatically.
Open `index.html` to view the site. The generated `assets/css/site.css` must be
included when publishing, so visitors do not need Node.js or Tailwind installed.
Do not edit the generated stylesheet: change HTML classes or `tailwind.config.js`,
then rebuild. `src/input.css` contains the Tailwind layer directives.

### Fonts

Outfit Bold is used for the site header and content headings. Inter is used for
body text, navigation and buttons. Google Fonts requires an internet connection; local
Arial fallbacks are provided.
