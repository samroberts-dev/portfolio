About me.

Hi, I’m Samuel Roberts.

I’m studying Certificate IV in Information Technology (Programming). I enjoy building websites, applications and creative digital projects, and using what I learn to turn ideas into working software.

My projects include a responsive web portfolio, a C# desktop application for exploring a MySQL database, and a Python guessing game with saved player statistics. These give me opportunities to practise different languages and work through practical programming problems.

I’m continuing to develop my skills in web development, databases and application programming. My focus is on writing clear code, creating useful interfaces and improving my projects as I learn.
